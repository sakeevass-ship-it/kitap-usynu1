# Кітап ұсыну жүйесі

## Іске қосу
1. Python 3.10 немесе одан жаңасын орнатыңыз.
2. Осы папкада Terminal / Command Prompt ашыңыз.
3. Кітапханаларды орнатыңыз:
   `pip install -r requirements.txt`
4. Қосымшаны іске қосыңыз:
   `streamlit run app.py`
5. Браузер автоматты түрде ашылады. Ашылмаса, терминалда көрсетілген Local URL-ды браузерге енгізіңіз.

## Мүмкіндіктер
- кітап каталогы және іздеу;
- жанр бойынша сүзу;
- TF-IDF + cosine similarity арқылы ұсыныс;
- онлайн сауалнама;
- жауаптарды Excel-ге автоматты сақтау;
- нәтижелер диаграммасы және Excel файлын жүктеу.

Ескерту: бұл нұсқада сауалнама Excel файлы қосымша іске қосылған компьютерде сақталады. Қосымшаны көпшілікке интернет арқылы жариялағанда тұрақты дерекқор немесе Google Sheets интеграциясын қолданған дұрыс.
